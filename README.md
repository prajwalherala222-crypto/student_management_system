# Student Management System
A Python-based Student Management System that performs CRUD operations and  JSON file storage.

## Features
- Add Student
- View All Students
- Search students
- Update student details
- Delete student
- Save Data in JSON file

## Technologies Used 
- Python
- JSON
- File Handling
- Functions
- Lists & Dictionaries

## Concepts Learned
- CRUD Operations
- File Handling
- Exception Handling
- Python Programming
